Índice de dados do Candeia

Aqui ficam os arquivos que o Candeia, um geocodificador de endereços brasileiros, baixa quando alguém consulta um endereço. Não é um site para navegar: é uma base de arquivos estáticos, lida por código.

Código no GitHub Pacote no npm Demo

O que é

O índice é uma transformação do Cadastro Nacional de Endereços para Fins Estatísticos (CNEFE) do Censo Demográfico 2022, divulgado publicamente pelo IBGE. O pipeline do repositório seleciona colunas, normaliza o nome da via, descarta as coordenadas de centróide, agrupa os pontos por via e comprime o resultado. Nenhum dado de outra fonte é acrescentado.

Cada município vira um arquivo. Quem consulta um endereço baixa só o município daquele endereço, e o servidor destes arquivos vê qual município foi pedido, nunca o endereço consultado.

De onde vêm esses números. Eles são calculados a partir do manifesto.json de cada versão no momento da publicação, não digitados à mão. O tamanho é a soma dos arquivos comprimidos; o manifesto não entra na conta. Uma versão publicada não muda: correção no índice sai em um caminho novo (v2, v3), e por isso os arquivos são servidos com cache de um ano.

Como usar

O caminho normal é pela biblioteca, que lê o manifesto, baixa o município pedido e confere o sha256 de cada arquivo.

// npm install candeia  (versão {{VERSAO_PACOTE}} na data desta publicação)
import { criarGeocodificador } from "candeia";

const geo = criarGeocodificador({
  base: "https://dados.lucasrikelmi.dev/cnefe2022/{{VERSAO_ATUAL}}/",
});
const r = await geo.geocodificar("Rua 8, Qd 21 Lt 4", {
  municipio: "5208707", // código IBGE do município
});

Quem preferir pode espelhar os arquivos no próprio servidor e apontar base para lá. A licença permite, com atribuição.

Formato

Tudo é JSON comprimido com gzip. Os caminhos abaixo são relativos à pasta da versão, por exemplo /cnefe2022/{{VERSAO_ATUAL}}/.

Manifestomanifesto.json: para cada município, o tipo (único ou fatiado), a contagem de entradas e de vias, e o nome, o tamanho e o sha256 de cada arquivo.
Município<UF>/<código IBGE>.json.gz: um dicionário que vai da via para a lista de pontos dela.
Município grande<UF>/<código IBGE>/index.json.gz com o índice de vias, mais fatias fNNN.json.gz. Cada via fica inteira em uma só fatia, então a consulta baixa o índice e a fatia da via pedida.
CamposVia, tipo de logradouro, número, quadra e lote, localidade, CEP, coordenada, nível da coordenada e a contagem de pontos repetidos.
Fora do índiceNome de estabelecimento, complemento de unidade (apartamento, sala) e qualquer outro campo do CNEFE.

Cliente fora do navegador. Os arquivos .gz são servidos sem Content-Encoding, para que o hash seja conferido sobre os bytes comprimidos. A Cloudflare barra assinaturas genéricas de cliente, como a do urllib do Python: mande um User-Agent próprio. O CORS é liberado para qualquer origem.

Limites

  • É um retrato de 2022. Endereço criado ou renomeado depois do Censo não está aqui.
  • Só o que o CNEFE tem. Endereço que o cadastro não registrou não é encontrado, e erro do cadastro vira erro do índice.
  • Sem coordenada de centróide. Pontos cuja coordenada no CNEFE é um centróide, e não a posição do endereço, foram descartados (níveis 5 e 6 de NV_GEO_COORD).
  • Índice não é resultado. A precisão de uma consulta depende do motor. As medições e as limitações delas estão no README do repositório.
